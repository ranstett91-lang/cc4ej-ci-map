# Data License

## Scope

This file governs the **curated data assets** in this repository that are the
original work of the Project Owner, distinct from the software code (which is
covered by `LICENSE.md`) and distinct from third-party public-domain data
(which carries the terms of its original provider, as listed in `NOTICE`).

The curated data assets covered by this file are:

- `pollutant_health_links.json` — hand-curated pollutant-to-health-endpoint
  linkage table with source citations, severity weights, and confidence
  ratings.
- The verified / corrected facility coordinates in `facilities.json` and the
  accompanying coordinate-audit narrative in `CONTEXT.md`. (EPA ECHO
  coordinates remain public domain; only the corrections, the audit
  methodology, and the curator's selection and annotation of facilities are
  covered here.)
- `communities.json` — curated Delaware community metadata, naming, and
  boundary selection.
- `reports.yaml` and `reports.json` — curated report entries and summaries.
- `chemical_disasters.json` — curated historical disaster entries and
  annotations.

Data sourced from U.S. federal agencies (EPA, CDC, Census), Delaware state
agencies, and other government bodies is **not** covered by this file; it
remains in its original legal status (U.S. public domain for federal data
unless otherwise noted) and is attributed in `NOTICE`.
